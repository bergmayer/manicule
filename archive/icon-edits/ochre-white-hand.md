# Ochre hand color correction

Edited with the built-in imagegen tool. The generated image was resized to
1024 × 1024 for the app-icon catalog, then copied unchanged to the in-app
image asset.

Outputs:

- `Manicule/Assets.xcassets/AppIconOchre.appiconset/AppIconOchre-1024.png`
- `Manicule/Assets.xcassets/IconOchre.imageset/IconOchre.png`

Edit target: the previous ochre icon. White-material reference: the existing
indigo icon.

Prompt:

> Use case: precise-object-edit. Asset type: existing square iOS app icon. Edit target: image 1, ochre background with a dark pointing hand. Image 2 is a reference ONLY for the hand's white color/material. Change only the dark hand and cuff in image 1 to neutral porcelain white, with subtle light-gray dimensional shading matching the white hand of image 2. Preserve the exact silhouette, position, size, finger anatomy, cuff, lighting direction, shadow, ochre background color and background texture of image 1. The hand must read as white, never black, beige or yellow. Keep a full square opaque 1024 by 1024 image, no text, no border, no rounded corners. Do not otherwise redesign the icon.
